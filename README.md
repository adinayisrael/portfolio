# Accessibility Updates

- Added clear navigation and main content structure to all three pages to improve accessibility and page organization.
- Updated text and background colors to meet WCAG AA contrast requirements.
- Tested `index.html`, `projects.html`, and `about.html` with WAVE and confirmed that all three pages have 0 errors and 0 contrast errors.

## Gestalt Principles

- **Similarity:** I used consistent heading styles, fonts, and design elements across my pages so related sections look like they belong together.
- **Proximity:** I grouped related text and content close together so users can easily understand which information belongs to each section.
